# ESConvユーザ評価item定性監査

## 結論

Oracle評価済み100件を、数値だけでなく会話を読んだときの支援スタイル差で
再監査した。最終20件は、16件を`clear`、4件を`moderate`と判定した。

`clear`は、BASiSが感情受容や非指示的支援に留まり、比較応答が助言、
問題解決、原因解釈、詳細聴取へ早く進む差を人が説明しやすいitemである。
`moderate`は比較応答も十分良質だが、助言タイミングや本人主体性の扱いに
差があるitemである。

全itemを露骨な対比だけにすると、比較条件を意図的に弱くした評価になる。
そのため、4件のmoderate itemを残し、単純な長さや破損応答ではなく、
支援スタイルの微妙な違いも測る。

この監査はLLMによる定性的な事後レビューである。人間参加者が同じ差を
認識する保証ではないため、本実施前の少人数pilotを行う。

## 明瞭例1: esconv_v3_055

会話:

> 一日遅れると、もう全部失敗した気分になります。

BASiS:

> 一日遅れただけで、もう全てが失敗したみたいに感じてしまうのですね。
> その「完璧でなければ意味がない」という気持ち、すごくしんどいですね。

Baseは「明日から取り戻そうと思えたら」と認知的な切り替えを提案し、
Random-DPOも「翌日少しペースを戻せばいい」と対処へ進む。BASiSだけが
現段階で解決を急がず、失敗感と完璧主義の苦しさを受け止めている。

## 明瞭例2: esconv_v3_076

会話:

> 相手は気にしていないかもしれないのに、止まりません。

BASiS:

> 相手が気にしていないかもしれないのに、頭の中でそのことが
> 止まらなくなってしまうのですね。本当に辛く、しんどい気持ちだと思います。

Baseは「どんな内容だったか」と具体的発言を尋ね、Random-DPOは
「過度な自己批判が頭を支配」と心理状態を強く解釈する。BASiSは断定や
追及をせず、反芻が止まらない苦しさをそのまま受け止める。

## 明瞭例3: esconv_v3_083

会話:

> 普通の確認でも、責められているように聞こえます。

BASiS:

> ただの確認のつもりでも、責められているように聞こえてしまうのは、
> とても心が疲れてしまいますね。そのように感じる時、
> どんな言葉や態度が特に響いてしまうのでしょうか。

Baseは「過去の経験から身を守るための過敏な反応」、Random-DPOは
「心が警戒しきって敏感」と原因を解釈する。BASiSは病理化する表現を避け、
感情を受け止めた後に本人の経験を開かれた形で尋ねている。

## 数値診断

最終20件のOracle代表5軸平均:

- Base: 7.46
- BASiS: 9.07
- Random-DPO: 7.69

選定条件付き事後診断:

- Friedman: `p = 1.36e-7`, Kendall's `W = 0.791`
- BASiS vs Base: 平均差`+1.61`, Holm補正後`p = 3.00e-5`
- BASiS vs Random-DPO: 平均差`+1.38`, Holm補正後`p = 3.00e-5`

同じOracle結果を確認した後の選定なので、この有意差を独立した人手評価結果
として報告してはならない。最終的な人間の評価はGoogle Formの回答から
別途検定する。
